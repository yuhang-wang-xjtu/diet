# 快捷菜品、图片与计算式

## 分类与方格

快捷食物先显示分类，选中分类后才显示该分类的食物方格。选餐页只展示当前有食物的分类，删除或移走最后一项后不再展示空分类；编辑菜品时仍可选默认分类或输入新分类。牛奶位于饮品。搜索食物时仍先选择对应分类。原材料配方添加原料时使用相同的分类选择方式。

分类与食物方格随整页上下滚动，没有固定高度的内层滚动列表。选餐时可在分类页、食物页和录入页顶部切换早餐、午餐、晚餐或零食；返回分类和继续录入都会保留所选餐次。点击食物方格直接进入数量录入；底部固定提供手动输入、新建快捷食物、管理已有菜品。返回录入页的上一步会保留选餐分类和浏览位置。手动输入页不再重复提供“从快捷食物填入”和“这一餐没吃”；没吃标记保留在餐次明细页。

默认分类各有对应食物图标，例如主食用米饭、饮品用牛奶、蔬果用西兰花；“原有菜品”和自定义分类使用通用便当图标。分类方格、管理页分类筛选及分类输入下拉菜单使用同一套素材。

已有自定义食物和配方没有分类字段时，显示在“原有菜品”。升级不重新计算它们的营养或改写历史记录。创建或编辑时可选择已有分类，也可输入新的分类名称。

## 管理已有菜品

首页“管理已有菜品”、设置 → 管理我的菜品，或快捷食物底部的“管理已有菜品”，进入独立管理页。按分类及名称筛选后，可点击方格编辑数值、参考份量、原材料配方、分类和图片，或删除快捷项。批量分类按钮只调整当前筛选显示的菜品，并显示将操作的数量。

修改、删除快捷项不会回写已经保存的饮食；配方原材料保存自己的营养快照。管理页可复制内置或已有食物，修改后保存为自己的快捷项。

## 导入与导出菜品

管理页顶部提供“导入菜品表 / 导出菜品表”。导出全部自定义菜品为JSON文件，保留原始营养精度、分类、快捷单位及克重、备注与来源、原材料配方和照片；内置图标无需重复保存图片文件。系统文件选择器让用户选择保存位置或打开文件，不上传数据。

导入前展示菜品数量与部分名称，确认后以新菜品加入，照片使用新的本机文件标识，避免覆盖已有照片。导入不会覆盖已有快捷菜品或修改饮食记录；同一文件重复导入会产生副本。原有的全部记录CSV用于健康记录存档，与菜品JSON文件分开。

## 食物图片

创建或编辑菜品、配方时点“从食物图标素材中选择”，可从54个内置食物图标中按分类筛选、搜索后点击选用。管理页点击菜品也可直接选图标。图标随安装包提供，离线可用；选择仅调整封面，不改写营养、克数或原料。编辑表单中取消保存会保留原封面，管理页直接选用后保存。

“从手机选择照片”仍使用系统文件选择器，应用压缩并保存到私有目录，不上传、不申请整库相册读取权限。升级保留已有照片。未选择图片、改用默认图片或照片文件不可用时，优先使用该内置食物或分类对应的图标。透明图标完整显示，手机照片保持封面裁切。

素材来自微软 [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)，采用MIT许可，完整声明见[第三方素材声明](../THIRD_PARTY_NOTICES.md)。应用内可通过图标选择器的“素材与许可”或设置中的“图标素材与许可”查看来源及授权原文。

用户照片与健康数据保存在手机，卸载会删除。CSV中保留分类和图片标识；内置图标使用稳定的`icon:`标识，照片继续使用原有文件标识，CSV不包含图片文件本身。

## 参考克数与实际克数

手动记餐默认按克输入，参考克数和实际克数留空各按100g。新建或编辑快捷食物只填写参考营养及快捷单位克重，不显示实际食用量和本次摄入预览。选择设定了单位克重的快捷食物或原料时，默认按该单位输入数量，也可切换到克数。依次填写热量、蛋白质、脂肪、碳水化合物和钠，按以下公式换算：

`本次摄入 = 参考营养 × 实际克数 ÷ 参考克数`

录入页先展示食物封面和参考热量，点击参考说明可展开营养编辑。设置过单位克重时，会提示例如“每1份（150g）”，数量默认1，支持0.5、2及计算式；切换克数时会换算当前数量，保留同一食用量。手动按克记录默认100g，也可点150g快捷填写；清空后仍按100g。下方显示本次热量及按蛋白质、脂肪、碳水化合物排序的营养预览。手动记录、快捷食物和配方原料共用这套表单。

例如每100g为200kcal、10g蛋白质，实际吃150g，则记为300kcal、15g蛋白质。保存后同时保留参考值与实际份量，编辑时重新从参考值换算，不在上一次实际结果上再乘一次。营养留空表示未知，0表示确实为零。

编辑快捷食物时，有重量的参考营养按100g换算后显示；选择记餐时按保存的单位克重换算，管理页仅修改分类、图片等信息时保留原始营养、克重与快捷单位。

没有保存重量的旧套餐、配方可直接按整份记录，默认1份，清空份数仍按1份，也支持半份、`1/2`、负数和0；不要求补填重量。此时参考营养代表整份，记录快照明确保存“份”单位，编辑时继续按份数计算，不把整份假定为100g。需要按克换算时，可选择“改按克记录”，补填真实成品克重；也可随时切回整份。

旧记餐没有克数时，编辑页暂按参考100g／实际100g载入，以保留原摄入总量；没有调整克数就不补写重量数据。保存快捷食物时只保存参考营养、单位及克重，不填写实际食用量。已有记录载入原来的实际克数，只有手动清空后才使用默认100g。未知熟重的整锅配方可直接按份记录，仅在按克换算时需提供真实成品克重，不会把整锅假定为100g。

## 计算式与显示

数值输入允许正常输入数字、运算符和其他字符，在离开输入框、点键盘完成或保存时才检查。支持加减乘除、括号、百分数、科学计数法，以及全角数字、`×`、`÷`。例如`17/4.18`、`(120+30)*2`、`200*12.5%`。

数值输入框向输入法声明带小数和负号的数字类型，不再以拼音文本类型打开。使用 Android 的 [`setRawInputType`](https://developer.android.com/reference/android/widget/TextView#setRawInputType(int)) 保留计算式及任意粘贴字符的输入能力；实际键盘布局由所用输入法提供。聚焦数值框时只显示一条算式符号栏，可在光标处插入 `+ − × ÷ ( ) %`，也可替换选中文字；切换输入框时符号栏随焦点移动，输入完成后再计算。

录入表单按可用输入框的顺序显示键盘“下一个”，点击后完成当前计算式并切换焦点，跳过禁用的输入框；最后一个输入框显示“完成”，点击后执行与保存按钮相同的校验和提交。计算式无效时保留输入并提示错误，不提交数据。

食物的热量、营养、克数和原料数量允许负数和0，不设正负或数值大小限制，也不会取绝对值或截为0。未知文字、单位、未完成表达式和非有限结果会提示错误；参考克数不能为0，因为换算需要除以参考克数。年龄、运动时长、步数等其他功能保留各自规则。

完成后数值最多显示两位小数，省去末尾的0，额外小数向零截断。显示格式不会改变未修改的已有数值，内部计算和保存保留原始精度。
