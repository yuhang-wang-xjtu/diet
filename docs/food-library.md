# 快捷菜品、图片与计算式

## 分类与方格

快捷食物先显示分类，选中分类后才显示该分类的食物方格。内置分类包含菜品、主食、饮品、蛋奶肉类、蔬果、佐料、零食；牛奶位于饮品。搜索食物时仍先选择对应分类。原材料配方添加原料时使用相同的分类选择方式。

已有自定义食物和配方没有分类字段时，显示在“原有菜品”。升级不重新计算它们的营养或改写历史记录。创建或编辑时可选择已有分类，也可输入新的分类名称。

## 管理已有菜品

设置 → 管理我的菜品，或快捷食物中的“管理已有菜品”，进入独立管理页。按分类及名称筛选后，可点击方格编辑数值、参考份量、原材料配方、分类和图片，或删除快捷项。批量分类按钮只调整当前筛选显示的菜品，并显示将操作的数量。

修改、删除快捷项不会回写已经保存的饮食；配方原材料保存自己的营养快照。内置参考食物可在选择份量时复制并修改，保存为自己的快捷项。

## 食物图片

用系统文件选择器选择一张图片，应用压缩并保存到私有目录，不上传、不申请整库相册读取权限。未选择图片、改用默认图片或图片文件不可用时，方格显示默认插画。可在管理页直接更换图片，也可在菜品编辑表单中选择。

图片与健康数据保存在手机，卸载会删除。CSV中可保留分类和图片标识，但不包含图片文件本身。

## 参考克数与实际克数

直接添加饮食时，可选择“直接填写本次营养总量”，或“按参考克数 / 实际克数换算”。后者填写参考克数及其对应的热量、营养，再填写实际食用克数：

`本次摄入 = 参考营养 × 实际克数 ÷ 参考克数`

例如每100g为200kcal、10g蛋白质，实际吃150g，则记为300kcal、15g蛋白质。保存后同时保留参考值与实际份量，编辑时重新从参考值换算，不在上一次实际结果上再乘一次。营养留空表示未知，0表示确实为零。

快捷食物有参考克重时会带入相同模式；未填写成品熟重的配方仍按整锅比例记录，不虚构克重。

## 计算式与显示

数值输入允许正常输入数字、运算符和其他字符，在离开输入框、点键盘完成或保存时才检查。支持加减乘除、括号、百分数、科学计数法，以及全角数字、`×`、`÷`。例如`17/4.18`、`(120+30)*2`、`200*12.5%`。

未知文字、单位、未完成表达式、除零及非有限结果会提示错误，不会擅自删除文字后猜测数值。每个字段继续执行各自的范围限制；整数分钟、年龄、步数也必须得到整数结果。

完成后数值最多显示两位小数，省去末尾的0，额外小数向零截断。显示格式不会改变未修改的已有数值，内部计算和保存保留原始精度。
