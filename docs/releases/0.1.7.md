轻衡首个 GitHub 正式发布版，版本 0.1.7，Android versionCode 10。

- 记录三餐、零食、热量与营养摄入，支持快捷食物、自定义食物及原材料配方计算。
- 输入个人资料后估算基础/静息代谢、全天消耗和营养参考目标，记录体重变化。
- 三餐提醒支持打开记餐、推迟30分钟和标记没吃。
- 支持健康连接步数、自选数据源和连接诊断；无健康连接时可主动启用手机本机计步，不读取小米私有历史。
- 设置内可检查本仓库的最新正式 Release，下载并校验 APK 后打开系统安装界面。
- 健康数据保存在本机，支持 CSV 导出；检查更新及下载时联网，不上传健康记录。

安装附件 `qingheng-0.1.7.apk`，支持 Android 8.0 及以上。本附件沿用此前开发包的签名，为 debug 构建。

此前开发包名为1.x，其版本比较会认为0.1.7较旧，请先手动下载附件覆盖安装一次；不要卸载旧版。内部版本号已提高，签名相同时可覆盖并保留记录。之后正式版本按0.x递增。
